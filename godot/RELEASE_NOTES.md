## Shores O' Fortune for Android and Windows: a view to fit your ship

The twenty-eighth build sets the farthest zoom by the ship you sail.

- **Smaller ships, closer view.** Zoomed all the way out (straight down or
  leaned over), a galleon sees as far as ever, a brigantine stops 10% nearer
  and a sloop 20%, so a small ship never shrinks to a speck in a big sea.

### Also from the last build

The twenty-seventh build tidies the Windows game's HUD.

- **Smaller and lighter.** On a computer the ship's card, the bottom bar,
  the strip under the minimap and its two buttons all sit smaller, so the
  sea gets the screen. The Ship's Hold popup, which came out at a phone's
  touch size, is now in step with the rest.
- **The same on every screen.** The interface follows your window's size
  and no longer balloons with Windows' display scaling, so a 1440p or 4K
  monitor sees the same neat layout, only sharper. Settings' Interface size
  still makes it bigger or smaller.
- **A tidier speed readout.** The knots now sit under the speed like a
  gauge's readout, next to the sail pips, instead of trailing off to the
  side.
